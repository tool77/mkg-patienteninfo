# Zahnloser Oberkiefer

Status: Portal-Arbeitsseite im Hauptprojekt vorhanden.

Zielmodul: Patientenaufklaerung fuer implantologische Versorgung des zahnlosen Oberkiefers.

Voraussichtliche Dateien:

```text
zahnloser_oberkiefer/
├── aufklaerung_skript.md
├── merkblatt_zahnloser_oberkiefer.html
├── merkblatt_zahnloser_oberkiefer_ausfuehrlich.html  # vorhanden als Portal-Arbeitsseite
└── merkblatt_zahnloser_oberkiefer_ausfuehrlich.docx
```

Inhaltliche Leitpunkte fuer die spaetere Ausarbeitung:

- festsitzend vs. herausnehmbar
- Anzahl und Verteilung der Implantate
- Sofortversorgung vs. gedeckte Einheilung
- Sinuslift, horizontale oder vertikale Augmentation als moegliche Zusatzmassnahmen
- Provisorium und bestehende Prothese
- DVT-Planung, Kostenrahmen und prothetische Schnittstelle mit dem Hauszahnarzt
- Risiken: Implantatverlust, Peri-Implantitis, Kieferhoehle/MAV, Knochenaufbauverlust, Prothesendruckstellen
