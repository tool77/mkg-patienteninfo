# Zahnloser Unterkiefer

Status: Portal-Arbeitsseite im Hauptprojekt vorhanden.

Zielmodul: Patientenaufklaerung fuer implantologische Versorgung des zahnlosen Unterkiefers.

Voraussichtliche Dateien:

```text
zahnloser_unterkiefer/
├── aufklaerung_skript.md
├── merkblatt_zahnloser_unterkiefer.html
├── merkblatt_zahnloser_unterkiefer_ausfuehrlich.html  # vorhanden als Portal-Arbeitsseite
└── merkblatt_zahnloser_unterkiefer_ausfuehrlich.docx
```

Inhaltliche Leitpunkte fuer die spaetere Ausarbeitung:

- herausnehmbare Deckprothese auf zwei oder mehr Implantaten vs. festsitzende Versorgung
- interforaminaere Implantatpositionen und Nervnaehe
- vorhandene Prothese, Umarbeitung und Provisorium
- Sofortbelastung nur bei geeigneter Primarstabilitaet
- DVT-Planung, Kostenrahmen und prothetische Schnittstelle mit dem Hauszahnarzt
- Risiken: Implantatverlust, Peri-Implantitis, Nervirritation, Prothesendruckstellen, Wundheilungsstoerung
